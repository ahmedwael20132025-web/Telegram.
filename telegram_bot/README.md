# بوت إنشاء الأكواد الاحترافي (Aiogram 3)

بوت تيليجرام متكامل لتوليد الأكواد بالذكاء الاصطناعي، بيع الملفات البرمجية، عضوية VIP،
نظام إحالة ومحفظة، صفحات ديناميكية بالكامل من لوحة الأدمن، ومولّد مشاريع كامل بالذكاء الاصطناعي.

## المتطلبات
- Python 3.12+
- توكن بوت تيليجرام من [@BotFather](https://t.me/BotFather)
- مفتاح Claude API و/أو OpenAI API (اختياري، يمكن ضبطه من لوحة الأدمن لاحقًا)

## التثبيت

```bash
python -m venv venv
source venv/bin/activate  # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

عدّل ملف `.env` وأضف:
- `BOT_TOKEN`: توكن البوت
- `SUPER_ADMINS`: معرّفك الرقمي في تيليجرام (يمكن الحصول عليه من بوتات مثل @userinfobot)

## التشغيل

```bash
python bot.py
```

عند أول تشغيل، سيتم إنشاء قاعدة البيانات وزرع الإعدادات الافتراضية تلقائيًا.

## الميزات الرئيسية

- **إنشاء الأكواد بالذكاء الاصطناعي**: وصف نصي → كود كامل + شرح + ملف ZIP عند الحاجة.
- **الدفع عبر Telegram Stars**: فاتورة رسمية حقيقية (Invoice) داخل تيليجرام لكل من إنشاء الأكواد،
  شراء الملفات، اشتراك VIP، ومولّد المشاريع — تأكيد فوري وتلقائي عبر `successful_payment`.
- **عضوية VIP** (باقات أسبوعية/شهرية/ربع سنوية/سنوية/مدى الحياة) تمنح: إنشاء أكواد بلا حدود،
  استخدام غير محدود لمولّد المشاريع، صلاحية رفع/تعديل مشاريع خاصة، تحميل ملفات حصرية مجانًا،
  وتخطي شرط الاشتراك الإجباري.
- **مولّد المشاريع بالذكاء الاصطناعي**: قوالب جاهزة (متجر، بوت دعم، بوت موسيقى...)، معالج إعداد
  تفاعلي يجمع BOT_TOKEN وADMIN_ID ويتحقق من صحتها، ثم يبني ZIP نهائي جاهز للتشغيل. عدد استخدامات
  مجانية قابل للتخصيص ثم مدفوع (أو غير محدود لأعضاء VIP). رفع مشروع موجود حصري لأعضاء VIP، مع فحص
  تحذيري تلقائي (إعلامي فقط) للأنماط الخطيرة الشائعة في الكود قبل التعديل — البوت لا يُشغّل أي كود
  مرفوع على الخادم، فقط يجهّزه كملف ZIP يقوم المستخدم بنشره على استضافته الخاصة.
- **الملفات البرمجية**: متجر ملفات جاهزة مع فئات وصور غلاف وتحميلات.
- **المحفظة والإحالة**: رصيد داخلي، طلبات سحب تُوافق عليها الإدارة، مكافآت إحالة قابلة للتخصيص.
- **الصفحات الديناميكية (Dynamic Pages & Navigation Builder)**: إنشاء صفحات غير محدودة من
  لوحة الأدمن (عنوان، وصف، نص، صور، فيديو، ملفات، أزرار فرعية) بدون أي تعديل على الكود، مع
  دعم تعدد اللغات وصلاحيات الوصول (الجميع/المشتركين فقط/الأدمن فقط).
- **إدارة الأزرار الديناميكية**: إنشاء/حذف/تعديل/إعادة ترتيب/إخفاء أي زر، وربطه بصفحة أو رابط
  خارجي أو قناة أو ميزة مدمجة أو إجراء مخصص — تُطبَّق التغييرات فورًا دون إعادة تشغيل البوت.
- **الاشتراك الإجباري**: قنوات متعددة قابلة للترتيب والتفعيل.
- **الكوبونات**: نسبة أو مبلغ ثابت، عام أو مخصص، بعدد استخدامات وتاريخ انتهاء.
- **الإذاعة**: نص/صورة/فيديو/ملف لكل المستخدمين مع تقرير نجاح/فشل.
- **النسخ الاحتياطي**: يدوي وتلقائي يومي مع الاحتفاظ بآخر 10 نسخ واستعادة بضغطة زر.
- **لوحة أدمن شاملة**: إحصائيات، مستخدمين، أرباح، سجلات، مزود الذكاء الاصطناعي، API Keys،
  حظر/فك حظر، وغيرها الكثير.

## هيكل المشروع

```
bot.py                  نقطة الانطلاق
config.py               الإعدادات العامة (من .env)
database/               نماذج SQLAlchemy وطبقة الوصول للبيانات
handlers/user/          معالجات المستخدم
handlers/admin/         معالجات لوحة الأدمن
middlewares/            جلسة قاعدة البيانات، تسجيل المستخدم، الحماية من السبام
services/               منطق الأعمال (AI، VIP، الإحالة، النسخ الاحتياطي، الإذاعة...)
states/                 حالات FSM
filters/                فلتر التحقق من الأدمن
keyboards/              لوحات المفاتيح الثابتة والديناميكية
locales/                نصوص عربي/إنجليزي
utils/                  أدوات مساعدة ومهام مجدولة
```

## ملاحظة أمنية
هذا المشروع لا يتضمن أي تكامل مع خدمات بيع أرقام هواتف مؤقتة (مثل 5sim) أو أي آلية لاستقبال
وإعادة توجيه رسائل التحقق (OTP) الخاصة بحسابات تيليجرام/واتساب تلقائيًا، لأن هذا النوع من
الخدمات يُستخدم غالبًا لتجاوز أنظمة التحقق بالهوية وإنشاء حسابات وهمية بالجملة.
