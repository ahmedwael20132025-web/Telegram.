# بوت توليد فيديوهات وصور بالذكاء الاصطناعي - نظام رصيد + لوحة تحكم داخل البوت

بوت تليجرام باحترافية عالية - قائمة كبيرة، توليد فيديو وصور، دفع يدوي أو بنجوم تليجرام،
وكل التحكم من داخل تليجرام نفسه (مفيش أي موقع ويب).

## 🗂 محتويات المشروع
- `bot.py` — البوت نفسه: القائمة، توليد الفيديو/الصور، شحن الرصيد، الدفع بالنجوم
- `admin_panel.py` — لوحة تحكم الأدمن كاملة كأزرار جوه البوت
- `db.py` — قاعدة البيانات (SQLite، ملف واحد `data.db`)
- `video_gen.py` — الاتصال بـ Replicate API لتوليد الفيديو
- `image_gen.py` — الاتصال بـ Replicate API لتوليد الصور
- `config.py` — تحميل متغيرات البيئة

## 🎛 قائمة البوت (تظهر بعد /start)
- 🎬 إنشاء فيديو (بيتخصم من الرصيد)
- 🖼 إنشاء صورة (مجاني بالكامل، من غير أي خصم)
- 💰 شحن رصيد (دفع يدوي أو بنجوم تليجرام)
- 💵 الأسعار (عرض سعر الفيديو الحالي)
- 👤 حسابي (الرصيد + هل أنت أدمن/مجاني)
- 📢 قناة البوت (بيظهر بس لو الأدمن حط رابط القناة من الإعدادات)
- 🛠 لوحة تحكم الأدمن (بيظهر بس لصاحب `ADMIN_TELEGRAM_ID` تحديداً)

### 🎨 تجربة توليد الفيديو/الصورة
1. المستخدم يكتب وصف تفصيلي
2. يختار الستايل: 📷 واقعي / 🎨 كرتون / 🌸 أنمي / 🖌️ رسم فني
3. (الفيديو بس) يختار المدة: 5/10/15 ثانية
4. شاشة مراجعة نهائية فيها الوصف والستايل والتكلفة قبل التأكيد
5. ينفّذ ويستلم النتيجة مباشرة في الشات

## 💡 فكرة الرصيد والأسعار
- **الفيديو**: بيتخصم من رصيد المستخدم (1 فيديو = 1 وحدة رصيد). السعر بالعملة المحلية والنجوم منفصلين تماماً، وانت بتحددهم من `/admin`.
- **الصور**: مجانية بالكامل دايماً، مش بتاخد من رصيد حد ولا محدودة بعدد.
- **الأدمن**: يستخدم كل حاجة في البوت (فيديو وصور) مجاناً تلقائياً، من غير ما يحتاج تضيف نفسك لقائمة "المستخدمين المجانيين".
- **مستخدمين مجانيين تانيين**: تقدر تضيف أي حد تاني (غيرك) من `/admin → المستخدمين المجانيين` يستخدم الفيديو من غير خصم.

## 💳 طرق الدفع
1. **دفع يدوي** (فودافون كاش / إنستاباي / أي حاجة تحددها): المستخدم يحول ويبعت سكرين شوت، وانت توافق/ترفض بزرار واحد من تليجرام.
2. **نجوم تليجرام ⭐**: دفع فوري وأوتوماتيك 100% - الرصيد يتضاف لحظة الدفع من غير أي تدخل منك.

### ⚠️ ملاحظة صريحة عن نجوم تليجرام
النجوم بتتجمع في **رصيد البوت نفسه** جوه تليجرام (مربوط بحساب اللي عمل البوت على BotFather)،
وانت بعدين تسحبها فلوس حقيقية عن طريق **Fragment**. مفيش طريقة برمجية تخلي النجوم تروح
لحساب تليجرام مختلف مباشرة وقت الدفع.

## ⚙️ خطوات التشغيل (على Railway)

### 1. ارفع المشروع على GitHub
اعمل ريبو جديد وارفعله كل الملفات (ملف `.env` ماينفعش يترفع - موجود في `.gitignore`).

### 2. اعمل مشروع جديد على Railway
railway.app → **New Project → Deploy from GitHub repo** واختار الريبو.

### 3. جهّز متغيرات البيئة (Variables)
- `BOT_TOKEN` — من @BotFather (`/newbot`)
- `REPLICATE_API_TOKEN` — من https://replicate.com/account/api-tokens (خليه سري، متبعتوش لحد)
- `ADMIN_TELEGRAM_ID` — آيدي حسابك على تليجرام (من بوت @userinfobot)

### 4. اضبط أمر التشغيل
**Settings → Deploy → Custom Start Command**:
```
python bot.py
```

## 🛠 استخدام لوحة التحكم
افتح شات البوت بحسابك انت (نفس `ADMIN_TELEGRAM_ID`) وابعت `/start` - هتلاقي زرار
**"🛠 لوحة تحكم الأدمن"** ظاهر في نفس القائمة، أو ابعت `/admin` في أي وقت. فيها:

- 📊 الإحصائيات
- ⚙️ الإعدادات العامة (نص الترحيب، زرار ورابط القناة)
- 💰 أسعار الفيديو (السعر المحلي والنجوم - منفصلين تماماً)
- 🔒 الاشتراك الإجباري (انضمام لقناة قبل استخدام البوت)
- 💳 طرق الدفع (إضافة/تفعيل/إيقاف/حذف)
- 📋 طلبات الشحن (قبول ✅ / رفض ❌ بزرار مباشر تحت كل طلب)
- 🆓 المستخدمين المجانيين (إضافة/إزالة - غير الأدمن اللي عنده وصول مجاني تلقائي)
- 👥 الأعضاء (لستة بصفحات، الرصيد وهل مجاني)
- 📢 رسالة جماعية

أي حد تاني غير الآيدي المحدد لو حاول `/admin` البوت مش هيرد عليه خالص.

## 🎬🖼 عن التوليد
- الفيديو: موديل `minimax/video-01` على Replicate (في `video_gen.py`)
- الصور: موديل `black-forest-labs/flux-schnell` على Replicate (في `image_gen.py`)
لو عايز تغيّر أي موديل، بدّل `MODEL_VERSION` في الملف المعني بأي موديل من
https://replicate.com/explore

## ⚠️ ملاحظات مهمة
- موافقة طلبات الدفع اليدوي يدوية (تشوف السكرين شوت وتضغط قبول/رفض).
- الرصيد بينخصم بعد نجاح التوليد بس - لو حصل خطأ، المستخدم مايخسرش رصيده.
- الاشتراك الإجباري محتاج تعمل البوت **أدمن** في القناة، وإلا مش هيقدر يتحقق من العضوية.
- قاعدة البيانات ملف `data.db` بيتعمل تلقائي أول تشغيل. اعمل نسخة احتياطية بين فترة وفترة،
  وعلى Railway استخدم **Volume** (Settings → Volumes) عشان الملف متتمسحش لو عملت Redeploy.
