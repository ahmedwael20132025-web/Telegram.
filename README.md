# بوت شراء وبيع نجوم تليجرام

## كيف يشتغل البوت (باختصار)
- **شراء**: الزبون يطلب كمية → يشوف السعر → يحول لك → يرسل صورة إثبات → توصلك رسالة بزرين (تأكيد/رفض) → لما تضغط تأكيد، البوت يطلب منك ترسل النجوم يدويًا (هدية) → تخبر الزبون تلقائيًا إنها بالطريق.
- **بيع**: الزبون يطلب كمية → يرسل النجوم لك كهدية → يضغط "أرسلت النجوم" → توصلك رسالة تأكيد → لما تتأكد إنك استلمتها فعليًا، تضغط تأكيد → البوت يذكّرك ترسل له المبلغ يدويًا.
- كل الأسعار والأرباح والطلبات محفوظة في قاعدة بيانات SQLite (`stars_bot.db`) تلقائيًا.

## خطوات التشغيل

### 1) جهّز البوت في تليجرام
1. افتح محادثة مع [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot` واتبع التعليمات، راح تحصل على **BOT_TOKEN**
3. افتح محادثة مع [@userinfobot](https://t.me/userinfobot) عشان تعرف **آيدي حسابك (ADMIN_ID)**

### 2) عدّل الإعدادات
افتح ملف `config.py` وحط:
- `BOT_TOKEN` = التوكن من BotFather
- `ADMIN_ID` = آيدي حسابك
- `ADMIN_TELEGRAM_USERNAME` = يوزرك (بدون @ أو معه، حسب رغبتك بالعرض)
- `BANK_DETAILS` = تفاصيل حسابك البنكي/المحفظة
- `BUY_PRICE_PER_STAR` و `SELL_PRICE_PER_STAR` = أسعارك (تقدر تغيرها لاحقًا من داخل تليجرام بالأوامر)

> ملاحظة أمان: لا تشارك ملف `config.py` بعد ما تحط فيه التوكن الحقيقي مع أي أحد.

### 3) ثبّت المتطلبات وشغّل البوت
```bash
pip install -r requirements.txt
python bot.py
```

### أوامر الأدمن (تكتبها بمحادثتك الخاصة مع البوت)
- `/setbuyprice 0.02` — تغيير سعر الشراء
- `/setsellprice 0.015` — تغيير سعر البيع
- `/pending` — عرض الطلبات المنتظرة للمراجعة
- `/stats` — إحصائيات الأرباح والطلبات المكتملة

## وين تشغّل البوت (لأنك ما تعرف بعد)

البوت لازم يشتغل 24 ساعة عشان ما يفوتك زبون. عندك 3 خيارات:

### الخيار الأسهل للبداية: استضافة سحابية مجانية/رخيصة
- **Railway.app** أو **Render.com**: ترفع الكود، تحط متغيرات البيئة (BOT_TOKEN، ADMIN_ID)، ويشتغل البوت تلقائيًا 24/7. فيه باقات مجانية محدودة تكفي للتجربة، وباقات مدفوعة رخيصة (~5 دولار) للاستمرارية.

### الخيار الأقوى: VPS صغير
- شركات زي **Hostinger** أو **Contabo** تعطيك VPS بحوالي 4-6 دولار شهريًا. تشغل عليه Python والبوت باستمرار باستخدام `screen` أو `pm2` أو `systemd` عشان يفضل شغال حتى لو سكرت الاتصال.

### تجربة سريعة من الهاتف (مؤقت فقط، غير موثوق للعمل الحقيقي)
- تطبيق **Termux** يخليك تشغل Python على أندرويد، لكن البوت يوقف إذا سكرت التطبيق أو طفى الهاتف — مو مناسب لمشروع تجاري حقيقي فيه فلوس زبائن.

**توصيتي**: ابدأ بـ Railway أو Render للتجربة السريعة والمجانية، ولما يكبر المشروع انتقل لـ VPS صغير.

## تنبيهات مهمة قبل ما تبدأ فعليًا
1. **المصدر**: تأكد عندك مصدر موثوق تشتري منه النجوم بالجملة بسعر أقل من سعر بيعك، وإلا ما راح تربح.
2. **التحقق من الدفع**: راجع كل صورة إثبات دفع بعينك قبل الضغط على "تأكيد" — لا تعتمد على الصورة وحدها لأنها ممكن تكون مزوّرة.
3. **حدود تليجرام**: إرسال النجوم كهدايا له حدود وقيود من تليجرام نفسه، تأكد إنك مطّلع على آخر سياسات تليجرام لهذا الموضوع قبل التوسع بكميات كبيرة.
4. هذا البوت **هيكل عملي متكامل** لإدارة الطلبات والدفع، لكن التنفيذ الفعلي لإرسال/استلام النجوم دائمًا يدوي منك حاليًا.
